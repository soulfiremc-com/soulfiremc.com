These recipes use the [pinned node baseline](/docs/sdk/compatibility).
Each download uses the client's `.soulfire-script.json` format and starts paused.
The repository checks node types, ports, required values, and edge compatibility.
Those checks do not replace validation on your installed backend.

## Greeting on join

[Download the join greeting](/docs/scripts/join-greeting.soulfire-script.json).
The graph connects **On Join** to **Send Chat**.
Set the message, save, enable, and start one bot.
Expect one message per join. Pause the script after the check.

Use the [first-script tutorial](/docs/scripting/first-script) for the complete procedure.

## Log a join without sending chat

[Download the join log](/docs/scripts/join-log.soulfire-script.json).
The graph connects **On Join** to **Print** and passes the trigger's username into the log message.
Save, enable, and start one bot.
Expect that account's username in the script log when it joins.

Pause the script and stop the bot after checking the result.

## Import procedure

1. Open the intended instance's **Scripts** page.
2. Create or open the script you want to replace.
3. Use the toolbar import action and select the download.
4. Review the graph, its paused state, and validation diagnostics.
5. Save the script before enabling it.

Import changes the graph in the editor. It is not a complete instance restore.
Use the toolbar export action to preserve your modified graph.
