## On Chat

`trigger.on_chat` (trigger)

Fires when a chat message is received

Also called: chat, message, text, say, talk, receive.

**Inputs**

None.

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `out` (Out) | `exec` | Execution output |
| `bot` (Bot) | `bot` | The bot that received the message |
| `message` (Message) | `any` | The chat message component |
| `messagePlainText` (Message (Plain Text)) | `string` | The chat message as plain text |
| `timestamp` (Timestamp) | `number` | Timestamp when the message was received |

[Implementation](https://github.com/soulfiremc-com/SoulFire/blob/eb2b29fb0a4190d759135270a63344d53fdcf819/mod/src/main/java/com/soulfiremc/server/script/nodes/trigger/OnChatNode.java)

## On Interval

`trigger.on_interval` (trigger)

Fires at a configurable interval. Does not provide a bot; use GetBots + ForEachBot downstream for bot actions.

Also called: interval, timer, repeat, periodic, schedule.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `intervalMs` (Interval (ms)) | `number` | `1000` | Interval in milliseconds between executions |

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `out` (Out) | `exec` | Execution output |
| `executionCount` (Execution Count) | `number` | Number of times this trigger has fired |
