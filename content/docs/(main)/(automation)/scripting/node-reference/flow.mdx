## Branch

`flow.branch`

Branches execution based on a boolean condition

Also called: if, condition, switch, split.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `in` (In) | `exec` | Optional | Execution input |
| `condition` (Condition) | `boolean` | `false` | Condition to evaluate |

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `exec_true` (True) | `exec` | Executes if condition is true |
| `exec_false` (False) | `exec` | Executes if condition is false |
| `branch` (Branch) | `string` | Which branch was taken |
| `condition` (Condition) | `boolean` | The evaluated condition |

## Cooldown

`flow.debounce`

Rate-limits execution by enforcing a cooldown period

Also called: Debounce, debounce, rate limit, throttle.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `in` (In) | `exec` | Optional | Execution input |
| `cooldownMs` (Cooldown (ms)) | `number` | `1000` | Milliseconds between allowed executions |
| `key` (Key) | `string` | `"default"` | Unique key for this debounce |

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `exec_allowed` (Allowed) | `exec` | Execution path if cooldown elapsed |
| `exec_denied` (Denied) | `exec` | Execution path if still in cooldown |
| `allowed` (Allowed) | `boolean` | Whether execution was allowed |
| `remainingMs` (Remaining (ms)) | `number` | Milliseconds until next allowed execution |
