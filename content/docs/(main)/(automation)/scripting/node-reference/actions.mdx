## Wait

`action.wait` (expensive operation)

Delays execution for a specified duration with optional random jitter

Also called: delay, sleep, pause, timer, jitter.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `in` (In) | `exec` | Optional | Execution input |
| `baseMs` (Duration (ms)) | `number` | `1000` | Base delay in milliseconds |
| `jitterMs` (Jitter (ms)) | `number` | `0` | Random jitter +/- this value (0 = no jitter) |
| `minMs` (Min (ms)) | `number` | `0` | Minimum delay (clamp) |
| `maxMs` (Max (ms)) | `number` | `60000` | Maximum delay (clamp) |

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `out` (Out) | `exec` | Execution output |
| `actualMs` (Actual (ms)) | `number` | Actual delay used |
