## Web Fetch

`network.web_fetch` (expensive operation)

Performs HTTP requests with full control over method, headers, and body

Also called: http, fetch, request, api, rest, web, url, get, post.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `in` (In) | `exec` | Optional | Execution input |
| `url` (URL) | `string` | Required | The URL to fetch |
| `method` (Method) | `string` | `"GET"` | HTTP method (GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS) |
| `headers` (Headers) | `string` | `"{}"` | JSON object of headers |
| `body` (Body) | `string` | `""` | Request body (for POST/PUT/PATCH) |
| `timeout` (Timeout) | `number` | `30000` | Timeout in milliseconds |

**Outputs**
