## JSON Get

`json.get`

Extracts a value from JSON using a path expression

Also called: json, get, extract, path, query, access.

**Inputs**

| Port | Type | Required / default | Description |
| --- | --- | --- | --- |
| `json` (JSON) | `string` | Required | JSON string or object |
| `path` (Path) | `string` | Required | Path expression (e.g., data.users[0].name) |
| `defaultValue` (Default) | `any` | `null` | Value if path not found |

**Outputs**

| Port | Type | Description |
| --- | --- | --- |
| `value` (Value) | `any` | Extracted value |
| `found` (Found) | `boolean` | Whether the path was found |

[Implementation](https://github.com/soulfiremc-com/SoulFire/blob/eb2b29fb0a4190d759135270a63344d53fdcf819/mod/src/main/java/com/soulfiremc/server/script/nodes/json/JsonGetNode.java)
