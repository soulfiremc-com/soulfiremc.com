Visual scripts connect event triggers, data operations, and bot actions.
The SoulFire backend executes the graph. The editor does not need to stay open.
Scripts belong to an instance and act within that instance's bot context.

## Learn by doing

[Build your first script](/docs/scripting/first-script) to send one message when a bot joins.
The tutorial includes a downloadable graph and a cleanup step.

## When to use another tool

Use the [SDK](/docs/sdk) for a program with external libraries, typed errors, and fleet coordination.
Use a [Fabric plugin](/docs/development) for custom backend events or direct Minecraft access.
[Compare automation methods](/docs/automation) before building a large workflow.
