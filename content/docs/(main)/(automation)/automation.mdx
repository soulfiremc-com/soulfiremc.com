SoulFire offers several ways to automate bots.
Choose the simplest one that can do your task.

| Goal | Use |
| --- | --- |
| Run one operator action | [Commands](/docs/reference/commands) |
| React to chat, timers, or events without writing code | [Visual scripting](/docs/scripting) |
| Write a TypeScript or Python program | [Official SDK](/docs/sdk) |
| Run a long job that continues after your program disconnects | [Durable tasks](/docs/sdk/tasks) |
| Play through Minecraft with one bot or a team | [Beat-game runner](/docs/sdk/automation) |
| Call APIs that a server plugin provides | [Plugin APIs](/docs/sdk/plugins) |
| Add new server features | [Plugin development](/docs/development) |

## How the pieces fit

SoulFire handles Minecraft connections, pathfinding, bot input, and reusable tasks.
Your script or program decides what to do and when.
For example, a collect-blocks task only collects blocks. Your program decides when to start it and how many blocks it needs.

The beat-game runner is a TypeScript package, `@soulfiremc/beat-game`, that runs in your own program.
It uses the SDK and can save and resume progress. You can change its plan without changing SoulFire.

<Callout type="info">
  SoulFireClient has no beat-game dashboard. Monitor the runner from your program's logs or your own UI.
</Callout>
