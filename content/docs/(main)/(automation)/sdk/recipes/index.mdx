Each recipe is a complete program that shows the same job in TypeScript and Python.

## Before you start

Complete the [SDK installation](/docs/sdk/compatibility) and one first program.
Unlike the first program, the recipes attach to a saved bot on a SoulFire backend that is already running.
They do not install a backend for you.

Set these values in the terminal that runs the recipe:

```bash
export SOULFIRE_URL="http://127.0.0.1:38765"
export SOULFIRE_TOKEN="your-api-token"
export SOULFIRE_INSTANCE_ID="your-instance-uuid"
export SOULFIRE_BOT_ID="your-bot-uuid"
```

- `SOULFIRE_URL` is the SoulFire API address, not the Minecraft server address.
- `SOULFIRE_TOKEN` is an API token. [Connect to an existing backend](/docs/sdk/discover-bots#connect-to-an-existing-backend) shows how to create one.
- `SOULFIRE_INSTANCE_ID` and `SOULFIRE_BOT_ID` identify the saved bot. [Find instance and bot IDs](/docs/sdk/discover-bots#find-instance-and-bot-ids) prints them.

## Pick a job

- [Reply to chat](/docs/sdk/recipes/reply-to-chat) when a player sends a message.
- [Collect blocks](/docs/sdk/recipes/collect-blocks) and wait for the durable task to finish.
- [Follow the entity under the cursor](/docs/sdk/recipes/follow-entity) with a connection safe reference.
- [Move items through a container](/docs/sdk/recipes/transfer-items) and close the menu safely.

## Run and stop a recipe

Save the code using the filename in its code block.
Run a TypeScript file with `bun run <filename.ts>`.
Run a Python file with your virtual environment's Python, such as `.venv/bin/python <filename.py>`.

Some recipes run until you press <kbd>Ctrl</kbd>+<kbd>C</kbd>. Others finish when their action or task completes.
When a recipe calls `bot.connect()`, it stops the bot on exit only if the recipe started it.
The follow recipe uses the lower-level `start` API, so its task keeps running after the program exits.
Cancel that task and stop the bot yourself when you are done.
See [bot state and task ownership](/docs/concepts/bot-lifecycle).
