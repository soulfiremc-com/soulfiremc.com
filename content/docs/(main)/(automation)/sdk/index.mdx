The SoulFire SDK lets your own program control one bot or a fleet.
SoulFire handles Minecraft connections, reconnects, permissions, tasks, and plugins.
These guides describe SDK `%SOULFIRE_SDK_VERSION%`. The TypeScript SDK uses Effect v4.
The Python SDK uses effect-py and requires CPython 3.14 or newer.

## Start here

1. [Install the SDK](/docs/sdk/compatibility) for your language.
2. Run your first program in [TypeScript](/docs/sdk/typescript) or [Python](/docs/sdk/python). It installs a local SoulFire server and sends one chat message.
3. [Reuse named instances and bots](/docs/sdk/discover-bots), or connect to a SoulFire server that is already running.
4. Copy a [recipe](/docs/sdk/recipes) for a common job.

## How the SDK is organized

```text
SoulFire client
├── server metadata, administration, and plugins
└── instance(instanceId)
    ├── fleet lifecycle, selectors, and task groups
    └── bot(botId)
        ├── synchronized state and events
        ├── world, registry, inventory, recipes, and chat
        ├── camera, player actions, and pathfinding
        ├── raw protocol access
        └── durable tasks
```

An instance groups bots that share settings and permissions.
Each Minecraft account is one bot in that instance.

## How guide snippets run

Most guide snippets are fragments. They assume an open connection inside a scoped workflow.
The [first programs](/docs/sdk/typescript) and [recipes](/docs/sdk/recipes) show the complete setup.

- **TypeScript:** put calls inside `Effect.gen` with `yield*`, wrap the workflow in `Effect.scoped`, and run it once with `Effect.runPromise`.
- **Python:** put calls inside an `@gen` function with `yield from`, wrap it in `scoped`, and run it once with `run_async`.

The scope owns connections, subscriptions, and other resources. It closes them when the workflow ends.
Keep code that reads a stream or session inside the same scope.

## Actions, streams, and tasks

- An **action** is one short operation, such as sending chat or clicking a slot. It finishes as completed, cancelled, or failed.
- A **stream** delivers updates over time, such as chat, inventory, or task progress.
- A **durable task** is longer work that runs on the SoulFire server. You can read its progress, cancel it, or find it again by ID. See [durable tasks](/docs/sdk/tasks).

`bot.connect()` starts the bot if needed and stops it again when the scope closes.
A bot that was already running stays running. See [bot lifecycle](/docs/concepts/bot-lifecycle).
