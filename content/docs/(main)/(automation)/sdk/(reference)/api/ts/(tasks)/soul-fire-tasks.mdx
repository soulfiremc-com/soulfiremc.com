**Class** in `tasks`. [Source](https://github.com/soulfiremc-com/SoulFire/blob/878ba24b85ee4a1ec170ed738b7664b61ace1a2d/sdk/typescript/src/tasks.ts#L974).

Long jobs the server runs for the bot. Each `x` starts a task and resolves
once accepted. Use `yield* task.result()` to wait for completion.
Each `runX` starts it and streams its events instead,
and the task is cancelled if the stream is.

**Import from:** `@soulfiremc/sdk`, `@soulfiremc/sdk/browser`, `@soulfiremc/sdk/node`, `@soulfiremc/sdk/bun`.
