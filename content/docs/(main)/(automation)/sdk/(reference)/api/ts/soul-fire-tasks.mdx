## start

Starts a task from its input message. `resultSchema` types `result()`.

```ts

  Input extends DescMessage,
  Result extends DescMessage | undefined = undefined,

  inputSchema: Input,
  input: MessageInitShape<Input>,
  resultSchema?: Result,
  options: TaskStartOptions = {},
```
