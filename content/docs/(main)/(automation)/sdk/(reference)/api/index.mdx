The reference uses the [documented SDK baseline](/docs/sdk/compatibility).
Generated signatures and option tables use one pinned source revision.

- [TypeScript methods](/docs/sdk/api/typescript) cover public client classes, their methods, and properties.
- [Python methods](/docs/sdk/api/python) cover public classes and their effect-py operations.
- [TypeScript option tables](/docs/sdk/api/types) are generated from the pinned source declarations.
- [Server RPC reference](/docs/openapi) covers unary HTTP/JSON endpoints. Streaming and native gRPC contracts are outside that schema.

Start with a [recipe](/docs/sdk/recipes) if you want a complete program.
