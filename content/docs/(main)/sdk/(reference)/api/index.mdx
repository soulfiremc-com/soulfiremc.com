The reference tracks the [SoulFire SDK source](https://github.com/soulfiremc-com/SoulFire/tree/main).
Generated signatures and option tables use one pinned source revision.

- [TypeScript methods](/docs/sdk/api/typescript) cover Effect connections, bots, chat, and durable tasks.
- [Python methods](/docs/sdk/api/python) cover effect-py connections, bots, chat, and durable tasks.
- [TypeScript option tables](/docs/sdk/api/types) are generated from the published SDK declarations.
- [Server RPC reference](/docs/openapi) covers the lower level HTTP and gRPC API.

Start with a [recipe](/docs/sdk/recipes) if you want a complete program.
