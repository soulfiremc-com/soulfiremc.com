The high level reference tracks [SoulFire SDK 2.10.0](https://github.com/soulfiremc-com/SoulFire/tree/2.10.0). Each method signature links to its source in that release.

- [TypeScript methods](/docs/sdk/api/typescript) cover the Effect and Promise entry points, bots, chat, and durable tasks.
- [Python methods](/docs/sdk/api/python) cover async and sync clients, bots, chat, and durable tasks.
- [TypeScript option tables](/docs/sdk/api/types) are generated from the published SDK declarations.
- [Server RPC reference](/docs/openapi) covers the lower level HTTP and gRPC API.

Start with a [recipe](/docs/sdk/recipes) if you want a complete program.
