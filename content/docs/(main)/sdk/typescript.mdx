## Install

<Tabs items={['npm', 'JSR']}>
  <Tab value="npm">
    ```bash
    pnpm add @soulfiremc/sdk
    ```
  </Tab>
  <Tab value="JSR">
    ```bash
    deno add jsr:@soulfiremc/sdk
    ```
  </Tab>
</Tabs>

The package requires Node.js 22 or newer for local server installation.
Connecting from a browser only requires `fetch`.

## Connect to an existing server

<Steps>
  <Step>
    ### Create the client

    ```ts
    import { SoulFire } from "@soulfiremc/sdk";

    const soulfire = SoulFire.connect({
      baseUrl: "https://soulfire.example.com",
      token: process.env.SOULFIRE_TOKEN,
    });
    ```
  </Step>

  <Step>
    ### Select and start a bot

    ```ts
    const instance = soulfire.instance("instance-uuid");
    const bot = instance.bot("bot-uuid");

    await bot.start();
    await bot.sendChat("Hello from TypeScript");
    ```
  </Step>
</Steps>

Starting a bot persists its desired state.
SoulFire keeps the bot running according to its reconnect settings until you call `stop()`.

## Control a group

```ts
await instance.start({ count: 25 });
await instance.stop({ botIds: ["bot-uuid-1", "bot-uuid-2"] });
await instance.restart();
```

`restart()` with no selection reconnects bots that are already desired.
It does not start stopped bots.

## Watch desired and runtime status

The stream begins with a complete snapshot and then sends updates:

```ts
const controller = new AbortController();

for await (const event of instance.watchBotStatuses({
  signal: controller.signal,
})) {
  switch (event.event.case) {
    case "snapshot":
      console.log(event.event.value.bots);
      break;
    case "update":
      console.log(event.event.value);
      break;
    case "removedBotId":
      console.log("Removed", event.event.value);
      break;
  }
}
```

Use `await bot.status()` for a one-off status read.

## Stream live bot events

`events()` stays open while the bot is stopped and follows the configured account across reconnects.
Its default filter includes status, state changes, chat, lifecycle, inventory, and damage:

```ts
for await (const event of bot.events()) {
  switch (event.event.case) {
    case "chat":
      console.log(event.event.value.plainText);
      break;
    case "inventory":
      console.log(event.event.value.state?.slots);
      break;
    case "status":
      console.log(event.event.value.runtimeState);
      break;
  }
}
```

Pass an `AbortSignal` in the call options when the stream belongs to a cancellable task.

## Control a live bot

Live actions resolve after the Minecraft game thread executes them.
Failed and cancelled actions throw `SoulFireActionError` with the action ID and structured server result.

```ts
import { ClickType } from "@soulfiremc/sdk";

await bot.sendChat("Hello from TypeScript");
await bot.selectHotbar(0);
await bot.clickInventory(12, ClickType.LEFT_CLICK);
await bot.transferInventorySlot(12);
await bot.moveInventoryStack(12, 36);

await bot.setMovement({ forward: true, sprint: true });
await bot.look(90, 0);
await bot.resetMovement();
```

World and interaction methods include `getBlock`, `findBlocks`, `listNearbyEntities`, `digBlock`, `placeBlock`, `useItem`, `releaseItem`, `attackEntity`, `interactEntity`, `swingArm`, and `respawn`.
`goTo` returns a progress stream, while `stopPathfinding` cancels the current path.

## Coordinate multiple controllers

Control leases are optional.
Acquiring one prevents another client from issuing actions for that configured bot until the lease is released or expires:

```ts
const lease = await bot.acquireControl(30);

try {
  await bot.sendChat("This action carries the lease token");
  await lease.renew(30);
} finally {
  await lease.release();
}
```

## Compose behaviors

The included behaviors are public-API building blocks, not server-side modes:

```ts
import {
  attackNearest,
  collectBlocks,
  runBehaviors,
} from "@soulfiremc/sdk";

const controller = new AbortController();

await runBehaviors(
  bot,
  [
    collectBlocks({ blockIds: ["minecraft:oak_log"], maxCount: 16 }),
    attackNearest({ entityTypes: ["minecraft:zombie"] }),
  ],
  { signal: controller.signal },
);
```

The package also exports `followEntity`, `autoEat`, and `build`.

## Provision instances and accounts

Operators can create a compartmentalized instance, authenticate a Minecraft account, and add it to that instance:

```ts
import { AccountTypeDeviceCode } from "@soulfiremc/sdk";

const instance = await soulfire.createInstance("automation");

for await (const step of instance.loginDeviceCode({
  service: AccountTypeDeviceCode.MICROSOFT_JAVA_DEVICE_CODE,
})) {
  if (step.data.case === "deviceCode") {
    console.log(step.data.value.verificationUri, step.data.value.userCode);
  }
  if (step.data.case === "account") {
    await instance.addAccounts([step.data.value]);
  }
}
```

The high-level instance wrapper also supports listing instances, metadata and setting updates, account refresh, credentials authentication, and account or proxy batch operations.

## Provision a local dedicated server

```ts
const soulfire = await SoulFire.install({
  directory: ".soulfire",
  onLog: console.log,
});

try {
  const bot = soulfire.instance("instance-uuid").bot("bot-uuid");
  await bot.start();

  console.log(soulfire.localServer?.version);
  console.log(soulfire.localServerLogs);

  await soulfire.restartLocalServer();
  await soulfire.stopLocalServer();
} finally {
  await soulfire.close();
}
```

<Callout type="info">
  Local installation and process management are Node.js features and are excluded from the browser execution path.
  Restarting preserves the installation directory, port, release, and root API token.
</Callout>

## Use an unwrapped RPC

The package exports generated Protobuf definitions for the complete API:

```ts
import { InstanceService } from "@soulfiremc/sdk/generated/soulfire/instance_pb";

const instances = soulfire.service(InstanceService);
const response = await instances.listInstances({});
```
