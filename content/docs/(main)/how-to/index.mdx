## Specific server behavior

Use [auto-register](/docs/how-to/auto-register) for an authentication plugin on an offline server.
Use [forwarding](/docs/how-to/forwarding-bypass), [server-list behavior](/docs/how-to/server-list-bypass), or [virtual host settings](/docs/how-to/fake-virtual-host) to reproduce those connection paths.
Record these settings with your test results.

## Automation and deployment

[Choose an automation method](/docs/automation) for repeated behavior.
Use [Run a SoulFire server](/docs/server) for deployment and maintenance.
