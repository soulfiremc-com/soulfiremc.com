Bot view shows the world around a connected bot.
Use it after a connection succeeds. It does not test authentication.

## Inspect one bot

1. Open the project's **Overview**.
2. Select a connected bot and open **Bot view**.
3. Compare the view with a normal player at the same location.

Check the position, dimension, loaded chunks, and nearby objects.
A bot can be connected before the world has loaded enough for the action you want.
[App navigation](/docs/how-to/gui-navigation#control-a-bot-in-bot-view) explains the permissions and control that Bot view needs.

## Capture an image

Run this in the project **Terminal**:

```text
bot DocsBot_1 export-basic-render 640 360
```

Width and height are optional. The maximum is 3840 by 2160.
Use `export-render-debug-dump` to collect camera and device details for a rendering problem.

The backend saves both exports in the project's object storage, in the `renders` folder.
The terminal prints the full path. To download the files, open the project folder over [WebDAV](/docs/how-to/webdav).

## Automate camera inspection

Use [SDK camera and maps](/docs/sdk/camera) for captures, streams, and world maps.
When you report a failed interaction, include the screenshot, the bot position, the connection state, and the action error.
