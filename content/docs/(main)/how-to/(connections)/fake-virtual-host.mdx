## What this changes

**Handshake host override** replaces the hostname and port that the bot sends in the Minecraft handshake.
SoulFire still opens the network connection to the address in **Bot Settings**.
Releases up to 2.10.7 call this feature **Fake Virtual Host**. The plugin ID stays `fake-virtual-host`.

Use it when a proxy or server routes or checks players by the hostname that they typed, for example:

- one proxy IP serves several domains
- you connect through a different address than normal players, such as a direct IP or an internal address
- server logic checks the handshake host for branding or access rules

<Callout type="info">
  This plugin changes only what hostname the server sees.
  If the backend expects forwarded player identity or IP data from a proxy, use [Player forwarding](/docs/how-to/forwarding-bypass).
  The plugin does not fix DNS, dead proxies, wrong ports, or invalid accounts.
</Callout>

## Configure Handshake host override

<Steps>
  <Step>
    ### Enable the plugin

    Open **Plugins** and enable **Handshake host override**.
  </Step>

  <Step>
    ### Set the hostname

    Set **Hostname** to the exact name that normal players use, such as `play.example.net`.
    The default is `localhost`.
  </Step>

  <Step>
    ### Set the port

    Set **Port** to the port that normal players use. The default is `25565`.
  </Step>

  <Step>
    ### Join with one bot

    Check that the bot reaches the expected server or lobby.
    If the network rejects the bot at once or sends it to the wrong backend, compare the hostname and port with a normal player's address.
  </Step>
</Steps>
