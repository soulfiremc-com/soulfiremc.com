SoulFire runs Minecraft clients without a game window. You control them from the desktop app, visual scripts, or an SDK.
Use it to test servers you operate, reproduce player workflows, and develop bot behavior.

## Connect your first bot

[Install SoulFire](/docs/start-here), then complete the [first-bot tutorial](/docs/start-here/gui-mode).
You will create one offline account, connect to a test server, send chat, and stop the bot.
No plugin or programming experience is required.

## Two different servers

The **SoulFire server** runs your bots and stores instance data.
The **Minecraft server** is the target that those bots join.
For a local first run, the desktop app starts the SoulFire server for you.
A remote SoulFire server uses the same client and workflows.

Use SoulFire on Minecraft servers that you own or have permission to test.
For support, bring the versions and relevant error from the [diagnostic checklist](/docs/troubleshooting#collect-a-useful-report).
