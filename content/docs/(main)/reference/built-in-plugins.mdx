SoulFire includes built-in plugins.
You can enable or disable each plugin for an instance.
Auto Armor, Auto Eat, and Auto Totem are disabled by default. Enable them when automatic inventory changes are needed.

| ID | Description | Author | License |
| --- | --- | --- | --- |
| `ai-chat-bot` | Allow players to chat with an AI | AlexProgrammerDE | AGPL-3.0 |
| `anti-afk` | Automatically moves x amount of blocks in a random direction to prevent being kicked for being AFK | AlexProgrammerDE | AGPL-3.0 |
| `auto-armor` | Automatically puts on the best armor | AlexProgrammerDE | AGPL-3.0 |
| `auto-chat-message` | Automatically sends messages in a configured delay | AlexProgrammerDE | AGPL-3.0 |
| `auto-eat` | Automatically eats food when hungry | AlexProgrammerDE | AGPL-3.0 |
| `auto-jump` | Automatically jumps randomly | AlexProgrammerDE | AGPL-3.0 |
| `auto-reconnect` | Automatically reconnects bots when they time out or are kicked | AlexProgrammerDE | AGPL-3.0 |
| `auto-register` | Automatically registers bots AuthMe servers | AlexProgrammerDE | AGPL-3.0 |
| `auto-respawn` | Automatically respawns after death | AlexProgrammerDE | AGPL-3.0 |
| `auto-totem` | Automatically puts totems in the offhand slot | AlexProgrammerDE | AGPL-3.0 |
| `captcha-solver` | Solve captchas | AlexProgrammerDE | AGPL-3.0 |
| `chat-logger` | Logs all received chat messages to the terminal Includes deduplication to prevent spamming the same message too often | AlexProgrammerDE | AGPL-3.0 |
| `client-brand` | Sends the client brand to the server | AlexProgrammerDE | AGPL-3.0 |
| `client-settings` | Sends client settings to the server | AlexProgrammerDE | AGPL-3.0 |
| `dialog-handler` | Handles server-sent dialogs and exposes them via gRPC | AlexProgrammerDE | AGPL-3.0 |
| `disconnect-logger` | Logs all bot disconnects to the terminal Includes deduplication to prevent spamming the same disconnect message too often | AlexProgrammerDE | AGPL-3.0 |
| `fake-virtual-host` | Fakes the virtual host | AlexProgrammerDE | AGPL-3.0 |
| `kill-aura` | Automatically attacks entities | AlexProgrammerDE | AGPL-3.0 |
| `server-list-bypass` | Pings the server list before connecting. (Bypasses anti-bots like EpicGuard) | AlexProgrammerDE | AGPL-3.0 |
| `forwarding-bypass` | Allows bypassing proxy forwarding | AlexProgrammerDE | AGPL-3.0 |

## How this list is generated

Run `print-docs plugins` in the console of the GUI, CLI, or dedicated server.
