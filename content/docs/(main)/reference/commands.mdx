## About commands

Commands show information or control bots through the SoulFire server.

## List of commands

| Command | Description |
| --- | --- |
| `help{:bash}` | Prints a list of all available commands |
| `generate-token api{:bash}` | Generate an API JWT for the current user |
| `generate-token webdav{:bash}` | Generate a WebDAV JWT for the current user |
| `set-email <email>{:bash}` | Set the email of the current user |
| `whoami{:bash}` | Show your current user |
| `plugins{:bash}` | Show all installed plugins |
| `stop{:bash}` | Shut down the SoulFire server. |
| `spark{:bash}` | Show Spark help |
| `spark <command>{:bash}` | Runs a spark subcommand |
| `move <entity>{:bash}` | Move selected bots to an entity |
| `move radius <radius>{:bash}` | Move selected bots to a random XZ position within the radius |
| `move <y>{:bash}` | Move selected bots to the Y coordinate |
| `move <x> <z>{:bash}` | Move selected bots to the XZ coordinates |
| `move <x> <y> <z>{:bash}` | Move selected bots to the XYZ coordinates |
| `collect <block> <amount> <searchRadius>{:bash}` | Make selected bots collect a block by name or tag |
| `follow <entity> <maxRadius>{:bash}` | Make selected bots follow an entity |
| `excavate rectangle <fromX> <fromY> <fromZ> <toX> <toY> <toZ>{:bash}` | Make selected bots dig a rectangular area between two coordinates |
| `excavate sphere <x> <y> <z> <radius>{:bash}` | Make selected bots dig a sphere with the specified radius |
| `lookat <x> <y> <z>{:bash}` | Make selected bots look at the block at the XYZ coordinates |
| `control forward{:bash}` | Toggle walking forward for selected bots |
| `control backward{:bash}` | Toggle walking backward for selected bots |
| `control left{:bash}` | Toggle walking left for selected bots |
| `control right{:bash}` | Toggle walking right for selected bots |
| `control jump{:bash}` | Toggle jumping for selected bots |
| `control sneak{:bash}` | Toggle sneaking for selected bots |
| `control reset{:bash}` | Resets the movement of selected bots |
| `mimic <entity>{:bash}` | Make selected bots mimic the movement of other entities |
| `useitem <hand>{:bash}` | Make selected bots use an item in the specified hand |
| `useitemon <blockX> <blockY> <blockZ> <face> <hand>{:bash}` | Make selected bots use an item on a block with the specified face and hand |
| `inventory close{:bash}` | Close the current inventory of selected bots. Then open the player inventory. |
| `inventory current{:bash}` | Show the current inventory of selected bots |
| `inventory left-click <slot>{:bash}` | Left-clicks the specified slot in the current inventory for selected bots |
| `inventory right-click <slot>{:bash}` | Right-clicks the specified slot in the current inventory for selected bots |
| `inventory left-click-outside{:bash}` | Left-clicks outside current inventory for selected bots |
| `inventory right-click-outside{:bash}` | Right-clicks outside current inventory for selected bots |
| `inventory middle-click <slot>{:bash}` | Middle-clicks the specified slot in the current inventory for selected bots |
| `inventory drop-one <slot>{:bash}` | Drops one item from the specified slot in the current inventory for selected bots |
| `inventory drop-all <slot>{:bash}` | Drops all items from the specified slot in the current inventory for selected bots |
| `interact <entity> <hand>{:bash}` | Make selected bots interact with an entity using the specified hand |
| `click left{:bash}` | Simulates a left mouse button click for selected bots (attack/break) |
| `click right{:bash}` | Simulates a right mouse button click for selected bots (use/interact) |
| `bots start{:bash}` | Set every configured bot in the selected instances to running |
| `bots stop{:bash}` | Set every configured bot in the selected instances to stopped |
| `online{:bash}` | Show connected bots in the selected instances |
| `say <message>{:bash}` | Make selected bots send a chat message or run a command |
| `respawn{:bash}` | Respawn selected bots |
| `health{:bash}` | Print the health of selected bots. |
| `export-map{:bash}` | Export all loaded maps as images. |
| `export-map <map_id>{:bash}` | Export a map as an image by its map ID. |
| `export-basic-render{:bash}` | Export a basic camera image of the world that the bot sees. |
| `export-basic-render <width> <height>{:bash}` | Export an image at a custom resolution. |
| `export-render-debug-dump{:bash}` | Export a POV image, camera settings, Vulkan device, and capture timing. |
| `export-render-debug-dump <width> <height>{:bash}` | Export a debug dump at a custom resolution. |
| `export-render-debug-dump <width> <height> <max_distance>{:bash}` | Export a debug dump at a custom resolution and maximum render distance. |
| `stop-task{:bash}` | Stop the current task of selected bots |
| `bot <bot_names> ...{:bash}` | Run a command for specific bots. Separate bot names with commas. |
| `instance <instance_names> ...{:bash}` | Run a command for specific instances. Separate instance names with commas. |
| `repeat <amount> ...{:bash}` | Repeat the command the specified number of times |

## Example

`move 578 65 100`
