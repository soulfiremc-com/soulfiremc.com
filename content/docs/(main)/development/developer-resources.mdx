## Artifact coordinates

Plugin projects depend on:

```text
groupId:    com.soulfiremc
artifactId: mod
repository: https://repo.codemc.org/repository/maven-public/
```

Use the version that matches your SoulFire backend. [Gradle and project layout](/docs/development/gradle-and-project-layout#published-coordinates) explains what to do when CodeMC does not list it.

## Built-in plugins to study first

If you only read a few internal plugins, read these:

| Plugin | Why it is useful |
| --- | --- |
| [AntiAFK](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/AntiAFK.java) | small, clean example of event hooks plus settings page registration |
| [AutoArmor](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/AutoArmor.java) | staged inventory control |
| [AutoEat](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/AutoEat.java) | action sequencing and fallback behavior |
| [CaptchaSolver](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/CaptchaSolver.java) | richer settings, multiple property types, and more complex behavior |
| [KillAura](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/KillAura.java) | metadata, control ownership, and manual task markers |
| [DialogHandler](https://github.com/soulfiremc-com/SoulFire/blob/main/mod/src/main/java/com/soulfiremc/server/plugins/DialogHandler.java) | bridging Minecraft dialog state into the API layer |
