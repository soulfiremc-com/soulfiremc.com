This page sets up a workspace that can build and debug a SoulFire plugin.

## Recommended stack

- **Java 25**: SoulFire and the plugin template build with JDK 25. An older JDK fails the build.
- **Gradle Wrapper**: use the wrapper from your plugin project and from the SoulFire source checkout.
- **IntelliJ IDEA**: recommended for Fabric Loom, Mixins, Lombok, and large Java source navigation.
- **A local SoulFire checkout**: the most reliable API reference.

## Clone the repos you need

Clone these repositories into the same parent directory:

```bash
git clone https://github.com/soulfiremc-com/SoulFire.git
git clone https://github.com/soulfiremc-com/SoulFirePluginExample.git
```

Use `SoulFirePluginExample` as the starting project.
Use the `SoulFire` source and Javadocs to check current APIs, built-in plugins, and proto contracts.
Check out the SoulFire tag that matches your backend, for example `git -C SoulFire checkout %SOULFIRE_SDK_VERSION%`.

## Recommended IntelliJ setup

1. Open the plugin project as a Gradle project.
2. Wait for Loom to finish its dependency setup. Errors shown before that are often false.
3. Install Lombok support if IntelliJ prompts you.
4. If you also open the SoulFire repository, import its inspection profile from `config/intellij_inspections.xml`.

Other IDEs work if they support the Gradle Kotlin DSL, annotation processing, and Loom dependency resolution.

## What to inspect in the SoulFire source tree

| Source location | Why it matters |
| --- | --- |
| `mod/src/main/java/com/soulfiremc/server/api` | Public plugin API classes such as `SoulFireAPI`, `Plugin`, and event types |
| `mod/src/main/java/com/soulfiremc/server/settings` | Typed settings model, property classes, and settings page registration |
| `mod/src/main/java/com/soulfiremc/server/bot` | `BotConnection`, `ControlState`, and `ControlTask` |
| `mod/src/main/java/com/soulfiremc/server/plugins` | Built-in plugins that show real patterns used by the project |
| `mod/src/main/java/com/soulfiremc/server/grpc` | How GUI and CLI actions are translated into in-process bot operations |
| `proto/src/main/proto/soulfire` | The wire contracts for server info, instance info, bot control, scripting, and more |

## Keep versions aligned

Match your plugin's SoulFire dependency to the SoulFire version you run.
The [CodeMC Maven metadata](https://repo.codemc.org/repository/maven-public/com/soulfiremc/mod/maven-metadata.xml) lists the published versions.
The template can pin an older version. [Align the template with your backend](/docs/development/first-plugin#align-the-template-with-your-backend) before you write code.
