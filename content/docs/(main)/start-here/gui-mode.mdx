## When to use GUI Mode

GUI mode lets you run SoulFire, view bot state, and change settings without terminal commands.

<Callout type="info">
  New users can start with `Integrated server (local)`.
  If you already run a remote SoulFire server, use `Dedicated server (remote)` instead.
  For the difference, see [Operation Modes](/docs/concepts/operation-modes).
</Callout>

## Before you start

- Install the desktop app from [Start Here](/docs/start-here).
- If you want to connect to a remote server, have the server URL and access token ready.
- If you only want to explore the interface, `Demo server` is useful, but it does not connect real bots.

## Connect your first bots

<Steps>
  <Step>
    ### Choose how to connect

    Launch SoulFire and pick one of the three connection options:

    - `Integrated server (local)` for a local first run
    - `Dedicated server (remote)` for an existing SoulFire server
    - `Demo server` to explore the UI without a live backend
  </Step>

  <Step>
    ### Create an instance

    Open **Instances**, click **Create Instance**, and give the instance a name.
    Each instance keeps its own bots, settings, scripts, accounts, proxies, and plugin configuration.
  </Step>

  <Step>
    ### Configure the target server

    Open **Bot Settings** and set the server address, join delays, protocol version, and timeouts.
    For most first runs, the defaults are enough except for the target server address.
  </Step>

  <Step>
    ### Add accounts or keep offline mode

    If the server allows offline accounts, SoulFire can generate names from the configured format.
    If you need Microsoft or Bedrock accounts, follow [Import Accounts](/docs/how-to/import-accounts).
  </Step>

  <Step>
    ### Add proxies if you need them

    Open **Proxy Settings** only if you want bots to connect through proxies.
    If you do, follow [Import Proxies](/docs/how-to/import-proxies).
  </Step>

  <Step>
    ### Start and monitor bots

    Return to **Overview**. Enter the number of stopped bots to connect, then click **Start**.
    To connect every stopped bot, click **Start all**.
    Each account is controlled independently. You can start, restart, or stop an individual bot from its context menu.
  </Step>
</Steps>

## Where common tasks live

- **Instances**: Create, open, and delete instances.
- **Overview**: Start, restart, stop, and inspect bots in the current instance.
- **Terminal**: Run SoulFire commands for the current instance.
- **Account Settings**: Import Microsoft, Bedrock, or offline accounts.
- **Proxy Settings**: Import and check proxies.
- **Plugins** and **Plugin Settings**: Enable plugins and change their options.
- **Scripts**: Create and manage visual automation for the instance.

For a fuller map of the interface, see [GUI Navigation](/docs/how-to/gui-navigation).
