This tutorial uses the desktop app. The app starts a SoulFire server on your computer for you.
It takes about ten minutes. At the end, you have one bot that you can start and stop.

## Before you start

- [Install the desktop app](/docs/start-here).
- Start a Java Minecraft server that you control, in offline mode, at `127.0.0.1:25565`.
- Keep the server console open, or join with a normal Minecraft client, so that you can see chat.

<Callout type="info">
  An offline account does not sign in with Microsoft, so it cannot join an online-mode server.
  For an online-mode server, [import a Microsoft account](/docs/how-to/import-accounts) and use its name instead of `DocsBot_1`.
</Callout>

## 1. Start SoulFire

Open SoulFire. On **Choose where SoulFire runs**, select **Run on this computer**.
Keep the default settings and select **Start local server**.
The first start downloads the SoulFire server, so it can take a minute.
Wait until the app shows the **Projects** page.

Do not use **Try the demo**. The demo shows sample data and cannot connect bots.

## 2. Create a project

Select **Create project**. Enter `Docs tutorial` as the project name, then select **Create and continue**.
A project holds the accounts, proxies, settings, and scripts for one group of bots.

The project opens with the **Connect your first bot** guide. The next steps follow this guide.

## 3. Choose the Minecraft server

In **Choose the Minecraft server**, check that **Address** is `127.0.0.1:25565`.
Set **Protocol Version** to the version of your Minecraft server. Then select **Continue**.

`127.0.0.1` is the computer that runs the SoulFire server.
If you later use a remote SoulFire server, enter an address that the remote computer can reach.

## 4. Add one offline account

In **Add bot accounts**, select **Create accounts**.
Set **Amount** to `1` and **Name format** to `DocsBot_%d`, then select **Generate**.
SoulFire replaces `%d` with a number, so the account is named `DocsBot_1`.
Select **Continue**.

## 5. Skip proxies

In **Add proxies**, select **Continue without proxies**.
The bot connects from your own IP address.

## 6. Start the bot

In **Review and start**, keep **Bots to start** at `1`, then select **Start 1 bot**.
Wait until the app shows **DocsBot_1 is connected**.
The Minecraft server must list `DocsBot_1` as a player.

If the bot does not connect, read the disconnect reason in the app.
For timeouts, version errors, or rejected logins, see [connection troubleshooting](/docs/troubleshooting/cannot-connect-or-times-out).

## 7. Send a message

In the project sidebar, open **Terminal** and run:

```text
bot DocsBot_1 say Hello from the SoulFire tutorial
```

The message from `DocsBot_1` must appear in the Minecraft server chat.
`bot DocsBot_1` selects the bot, and `say` sends a chat message as that bot.

## 8. Stop the bot

Open **Overview** and select **Stop 1 bot**.
`DocsBot_1` must leave the Minecraft server.

The SoulFire server keeps bots running until you stop them.
If you close the app while it uses a remote SoulFire server, the bots keep running.
