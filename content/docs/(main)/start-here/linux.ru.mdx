## Установка SoulFire [#install-soulfire]

<Steps>
  <Step>
    ### Установите Flatpak [#install-flatpak]
    Установите `flatpak` по [официальной инструкции](https://flathub.org/setup).
  </Step>

  <Step>
    ### Установите SoulFire [#install-soulfire-1]
    Выполните эту команду в терминале:
    ```bash
    flatpak install flathub com.soulfiremc.soulfire
    ```

    Подтвердите запросы. Скриншоты и сведения о выпусках доступны на странице [SoulFire на Flathub](https://flathub.org/apps/com.soulfiremc.soulfire).
  </Step>

  <Step>
    ### Запустите SoulFire [#start-soulfire]
    Откройте SoulFire из меню приложений.
    Также можно выполнить в терминале `flatpak run com.soulfiremc.soulfire{:bash}`.
  </Step>
</Steps>

Если вы не хотите использовать Flatpak, в [выпуске на GitHub](https://github.com/soulfiremc-com/SoulFireClient/releases/latest) также есть пакеты AppImage, `.deb`, `.rpm` и pacman.
