## Установка SoulFire [#install-soulfire]

Выполните эти шаги, чтобы установить SoulFire в Windows.

<Steps>
  <Step>
    ### Скачайте SoulFire [#download-soulfire]
    Откройте [страницу загрузки](/download).
    Выберите Windows и архитектуру процессора, затем скачайте последний установщик `.exe`.
  </Step>

  <Step>
    ### Запустите установщик [#run-the-installer]
    Откройте папку загрузок и дважды щёлкните установщик.
  </Step>

  <Step>
    ### Подтвердите предупреждение [#accept-the-warning]
    Браузер или Windows Defender может показать предупреждение.
    В Windows Defender выберите **Подробнее** (**More info**), затем **Выполнить в любом случае** (**Run anyway**).

    Так часто бывает с новыми программами, у которых пока мало истории загрузок.
  </Step>

  <Step>
    ### Пройдите шаги установщика [#follow-the-installer]
    Следуйте инструкциям.
    Оставьте настройки по умолчанию, если вам не нужно их менять.
  </Step>

  <Step>
    ### Запустите SoulFire [#start-soulfire]
    Откройте SoulFire из меню «Пуск», через значок на рабочем столе или поиск Windows.
  </Step>
</Steps>
