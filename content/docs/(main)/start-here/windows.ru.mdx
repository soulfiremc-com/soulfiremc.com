## Установка SoulFire [#install-soulfire]

<Steps>
  <Step>
    ### Скачайте SoulFire [#download-soulfire]
    Откройте [страницу загрузки](/download).
    Страница определяет вашу систему и процессор. Убедитесь, что выбрана Windows, затем скачайте установщик `.exe`.
  </Step>

  <Step>
    ### Запустите установщик [#run-the-installer]
    Откройте папку загрузок и дважды щёлкните установщик.

    Microsoft Defender SmartScreen может показать окно **Система Windows защитила ваш компьютер**, потому что установщик новый и не подписан.
    Выберите **Подробнее**, затем **Выполнить в любом случае**.
  </Step>

  <Step>
    ### Запустите SoulFire [#start-soulfire]
    Установщик ничего не спрашивает. Он устанавливает SoulFire для вашей учётной записи и открывает приложение на экране **Подключение к серверу SoulFire** (по-английски **Choose where SoulFire runs**).
    В дальнейшем открывайте SoulFire из меню «Пуск» или через ярлык на рабочем столе.
  </Step>
</Steps>
