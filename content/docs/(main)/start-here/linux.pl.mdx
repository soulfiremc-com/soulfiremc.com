## Zainstaluj SoulFire [#install-soulfire]

<Steps>
  <Step>
    ### Zainstaluj Flatpak [#install-flatpak]
    Zainstaluj `flatpak` według [oficjalnej instrukcji instalacji](https://flathub.org/setup).
  </Step>

  <Step>
    ### Zainstaluj SoulFire [#install-soulfire-1]
    Uruchom to polecenie w terminalu:
    ```bash
    flatpak install flathub com.soulfiremc.soulfire
    ```

    Potwierdź pytania instalatora. Zrzuty ekranu i szczegóły wydań znajdziesz na stronie [SoulFire w serwisie Flathub](https://flathub.org/apps/com.soulfiremc.soulfire).
  </Step>

  <Step>
    ### Uruchom SoulFire [#start-soulfire]
    Otwórz SoulFire z menu aplikacji.
    Możesz też uruchomić w terminalu `flatpak run com.soulfiremc.soulfire{:bash}`.
  </Step>
</Steps>

Jeśli nie chcesz używać Flatpaka, [wydanie na GitHubie](https://github.com/soulfiremc-com/SoulFireClient/releases/latest) zawiera też pakiety AppImage, `.deb`, `.rpm` i pacman.
