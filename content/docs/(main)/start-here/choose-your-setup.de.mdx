<Callout type="info">
  Wenn du unsicher bist, nutze die Desktop-App und wähle **Integrierter Server (lokal)**. Die englische App nennt diese Option **Run on this computer**.
</Callout>

SoulFire besteht aus zwei Teilen. Ein **Client** ist die App, mit der du Bots steuerst: die Desktop-App (GUI) oder der Terminal-Client (CLI).
Ein **SoulFire-Server** führt die Bots aus und verbindet sie mit dem Minecraft-Server.
Der Client kann einen eigenen Server auf deinem Computer starten oder sich mit einem Server verbinden, der woanders läuft.

| Wenn du... | Beginne mit... | Warum |
| --- | --- | --- |
| SoulFire mit möglichst wenig Einrichtung kennenlernen willst | [Deinen ersten Bot verbinden](/docs/start-here/gui-mode) | Die Desktop-App startet für dich einen Server auf deinem Computer |
| Bots auf einem VPS laufen lassen oder mit anderen Nutzern teilen willst | [Dedizierter Server](/docs/server) | Bots laufen weiter, wenn du den Client schließt, und mehrere Clients können sich verbinden |
| aus einem Terminal automatisieren oder einen Computer ohne Desktop nutzen willst | [CLI-Modus](/docs/start-here/cli-mode) | Funktioniert in Skripten und SSH-Sitzungen |

## Empfohlene Wege [#recommended-paths]

### Neue Nutzer [#new-user]

1. [Installiere SoulFire](/docs/start-here).
2. [Verbinde deinen ersten Bot](/docs/start-here/gui-mode).
3. Nutze das [Benutzerhandbuch](/docs/how-to) für Konten, Proxys, Plugins und Integrationen.

### Betrieb auf einem entfernten Server [#remote-operator]

1. [Richte einen dedizierten Server ein](/docs/server), mit dem Setup-Skript, Docker oder Java.
2. Wähle in der Desktop-App **Dedizierter Server (Remote)** (englisch **Connect to a SoulFire server**). Gib die Server-URL und ein Zugriffstoken ein. Unter [Serverzugriff](/docs/server/access) erfährst du, wie du das Token erstellst.
3. Nutze die [Serververwaltung](/docs/server) für Upgrades, Backups und Zugriff.

### Automatisierung [#automation-user]

1. Entscheide, ob die CLI einen eigenen Server startet oder sich mit einem entfernten Server verbindet.
2. Lies [CLI-Modus](/docs/start-here/cli-mode).
3. Lies [Automatisierung](/docs/automation) und wähle eine Automatisierungsmethode.
4. Halte die [CLI-Flags](/docs/reference/cli-flags) als Referenz offen.
