## Die Kurzfassung [#the-short-version]

| Wenn du... | Beginne mit... | Warum |
| --- | --- | --- |
| SoulFire mit möglichst wenig Einrichtung kennenlernen willst | [Deinen ersten Bot verbinden](/docs/start-here/gui-mode) | Braucht die wenigsten Einrichtungsschritte |
| Bots auf einem VPS oder gemeinsam genutzten Rechner laufen lassen willst | [Dedizierter Server](/docs/server/automated-setup) | Das Backend läuft weiter, auch wenn die GUI geschlossen ist |
| aus einem Terminal automatisieren oder ein System ohne Desktop nutzen willst | [CLI-Modus](/docs/start-here/cli-mode) | Eignet sich gut für Skripte und SSH-Sitzungen |
| ein Backend mit mehreren Nutzern oder Clients teilen willst | [Dedizierter Server](/docs/server/automated-setup) | GUI- und CLI-Clients können sich mit demselben entfernten Server verbinden |

## Was die einzelnen Teile bedeuten [#what-each-part-means]

### GUI-Client [#gui-client]

Die GUI ist die Desktop-App.
Damit erstellst du Instanzen, änderst Einstellungen, siehst den Bot-Status und verwaltest Plugins oder Skripte.

### CLI-Client [#cli-client]

Die CLI ist der Terminal-Client.
Nutze sie für Automatisierung, SSH-Sitzungen oder Systeme ohne Desktop.

### Integrierter Server [#integrated-server]

GUI und CLI enthalten einen SoulFire-Server.
Du kannst Bots auf deinem Computer ohne separaten Server betreiben.

### Dedizierter Server [#dedicated-server]

Ein dedizierter Server betreibt SoulFire getrennt, meist auf einem anderen Computer.
GUI- und CLI-Clients verbinden sich über das Netzwerk mit ihm.

## Empfohlene Wege [#recommended-paths]

### Neue Nutzer [#new-user]

1. [Installiere SoulFire](/docs/start-here)
2. [Starte deine ersten Bots im GUI-Modus](/docs/start-here/gui-mode)
3. Nutze das [Benutzerhandbuch](/docs/how-to) für Konten, Proxys, Plugins und Integrationen

### Betrieb auf einem entfernten Server [#remote-operator]

1. [Richte einen dedizierten Server ein](/docs/server/automated-setup)
2. Verbinde dich in der GUI mit der Server-URL und dem Zugriffstoken
3. Nutze das [Benutzerhandbuch](/docs/how-to) für die laufende Verwaltung

### Automatisierung [#automation-user]

1. Entscheide, ob die CLI einen lokalen oder entfernten Server nutzt
2. Lies [CLI-Modus](/docs/start-here/cli-mode)
3. Lies [Automatisierung](/docs/automation) und wähle eine Automatisierungsmethode
4. Halte die [CLI-Flags](/docs/reference/cli-flags) als Referenz offen
