## SoulFire installieren [#install-soulfire]

Mit diesen Schritten installierst du SoulFire unter Linux.

<Steps>
  <Step>
    ### Flatpak installieren [#install-flatpak]
    Installiere `flatpak` mit der [offiziellen Installationsanleitung](https://flathub.org/setup).
  </Step>

  <Step>
    ### SoulFire installieren [#install-soulfire-1]
    Führe diesen Befehl in einem Terminal aus:
    ```bash
    flatpak install flathub com.soulfiremc.soulfire
    ```

    Screenshots und Release-Details findest du unter [SoulFire auf Flathub](https://flathub.org/apps/com.soulfiremc.soulfire).
  </Step>

  <Step>
    ### Installation abschließen [#complete-the-installation]
    Bestätige die Installationsabfragen.
  </Step>

  <Step>
    ### SoulFire starten [#start-soulfire]
    Öffne SoulFire über das Anwendungsmenü.
    Du kannst auch `flatpak run com.soulfiremc.soulfire{:bash}` in einem Terminal ausführen.
  </Step>
</Steps>
