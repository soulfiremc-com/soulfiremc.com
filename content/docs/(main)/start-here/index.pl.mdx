Zacznij od aplikacji komputerowej i opcji **Integrated server (local)**.
Aplikacja uruchamia lokalny backend SoulFire, więc nie potrzebujesz Dockera ani osobnej instalacji Javy.

## 1. Zainstaluj aplikację [#1-install-the-app]

<Cards>
<Card title="Windows" href="/docs/start-here/windows">Zainstaluj aplikację dla Windows.</Card>
<Card title="macOS" href="/docs/start-here/macos">Zainstaluj aplikację dla macOS.</Card>
<Card title="Linux" href="/docs/start-here/linux">Zainstaluj aplikację dla Linux przez Flatpak.</Card>
</Cards>

## 2. Połącz jednego bota [#2-connect-one-bot]

Wykonaj samouczek [Połącz pierwszego bota](/docs/start-here/gui-mode).
Przygotuj testowy serwer Minecraft. Samouczek używa serwera Java w trybie offline pod adresem `127.0.0.1:25565`.
Dla serwera w trybie online użyj konta Microsoft.

Test kończy się powodzeniem, gdy bot dołączy, wyśle widoczną wiadomość i rozłączy się po zatrzymaniu.

## 3. Wybierz następne zadanie [#3-choose-your-next-task]

- [Przetestuj serwer](/docs/testing) w powtarzalnym przebiegu.
- [Utwórz skrypt wizualny](/docs/scripting) bez pisania kodu.
- [Użyj SDK](/docs/sdk) z TypeScript lub Python.

## Inne sposoby instalacji [#other-installation-paths]

Przeczytaj [Wybierz konfigurację](/docs/start-here/choose-your-setup), jeśli potrzebujesz zdalnego backendu lub pracy w terminalu.
Działający stale backend opisuje poradnik [Uruchom serwer SoulFire](/docs/server).
Użyj [trybu CLI](/docs/start-here/cli-mode) do sesji w terminalu.
