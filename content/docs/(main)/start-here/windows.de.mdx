## SoulFire installieren [#install-soulfire]

Mit diesen Schritten installierst du SoulFire unter Windows.

<Steps>
  <Step>
    ### SoulFire herunterladen [#download-soulfire]
    Öffne die [Download-Seite](/download).
    Wähle Windows und deine CPU-Architektur und lade dann das neueste `.exe`-Installationsprogramm herunter.
  </Step>

  <Step>
    ### Installationsprogramm ausführen [#run-the-installer]
    Öffne den Download-Ordner und doppelklicke auf das Installationsprogramm.
  </Step>

  <Step>
    ### Warnung bestätigen [#accept-the-warning]
    Dein Browser oder Windows Defender kann eine Warnung anzeigen.
    Wähle in Windows Defender **Weitere Informationen** (**More info**) und dann **Trotzdem ausführen** (**Run anyway**).

    Das ist bei neuerer Software üblich, die noch wenig Download-Verlauf hat.
  </Step>

  <Step>
    ### Installationsprogramm durchlaufen [#follow-the-installer]
    Folge den Anweisungen.
    Behalte die Standardeinstellungen, sofern du nichts ändern musst.
  </Step>

  <Step>
    ### SoulFire starten [#start-soulfire]
    Öffne SoulFire über das Startmenü, das Desktopsymbol oder die Windows-Suche.
  </Step>
</Steps>
