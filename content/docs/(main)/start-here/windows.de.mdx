## SoulFire installieren [#install-soulfire]

<Steps>
  <Step>
    ### SoulFire herunterladen [#download-soulfire]
    Öffne die [Download-Seite](/download).
    Die Seite erkennt dein System und deinen Prozessor. Prüfe, ob Windows angezeigt wird, und lade dann das `.exe`-Installationsprogramm herunter.
  </Step>

  <Step>
    ### Installationsprogramm ausführen [#run-the-installer]
    Öffne den Download-Ordner und doppelklicke auf das Installationsprogramm.

    Microsoft Defender SmartScreen kann **Der Computer wurde durch Windows geschützt** anzeigen, weil das Installationsprogramm neu und nicht codesigniert ist.
    Wähle **Weitere Informationen** und dann **Trotzdem ausführen**.
  </Step>

  <Step>
    ### SoulFire starten [#start-soulfire]
    Das Installationsprogramm braucht keine Eingaben. Es installiert SoulFire für dein Benutzerkonto und öffnet die App auf dem Bildschirm **Verbinde dich mit einem SoulFire Server** (englisch **Choose where SoulFire runs**).
    Später öffnest du SoulFire über das Startmenü oder die Desktopverknüpfung.
  </Step>
</Steps>
