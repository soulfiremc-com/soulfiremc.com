## Install SoulFire

Follow these steps to install SoulFire on macOS.

<Steps>
  <Step>
    ### Download SoulFire
    Open the [download page](/download).
    Select macOS and your CPU architecture, then download the latest `.dmg` file.
  </Step>

  <Step>
    ### Run the installer
    Open the downloads list in the toolbar.
    Hold `Control` and click the installer, then select **Open**.

    macOS can block the installer if you open it without the `Control` key.
  </Step>

  <Step>
    ### Accept the warning
    If macOS warns you about an unidentified developer, continue with the installation.
  </Step>

  <Step>
    ### Follow the installer
    Follow the instructions and accept the license.
    Keep the default settings unless you need to change them.
  </Step>

  <Step>
    ### Start SoulFire
    Open SoulFire from the Applications folder.
  </Step>
</Steps>
