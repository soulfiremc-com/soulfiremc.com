## Install SoulFire

Follow these steps to install SoulFire on macOS.

<Steps>
  <Step>
    ### Download SoulFire
    Open the [download page](/download).
    Select macOS and your CPU architecture, then download the latest `.dmg` file.
  </Step>

  <Step>
    ### Copy SoulFire to Applications
    Open the downloaded `.dmg` file.
    Drag **SoulFire** into the **Applications** folder, then eject the disk image.
  </Step>

  <Step>
    ### Allow the first start
    Open SoulFire from the Applications folder.
    macOS blocks the first start because the app is not notarized by Apple.

    On macOS 15 or newer:

    1. Close the warning.
    2. Open **System Settings**, then **Privacy & Security**.
    3. Scroll to **Security** and select **Open Anyway** next to the SoulFire message.
    4. Confirm with your password, then select **Open Anyway** again.

    On macOS 14 or older, hold `Control`, click the app, and select **Open** twice.
    You only do this once for each installed version.
  </Step>

  <Step>
    ### Start SoulFire
    Open SoulFire from the Applications folder or Launchpad.
    Expect the **Choose where SoulFire runs** screen.
  </Step>
</Steps>
