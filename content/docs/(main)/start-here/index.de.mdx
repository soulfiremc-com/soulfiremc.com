Beginne mit der Desktop-App und **Integrierter Server (lokal)**. Die englische App nennt diese Option **Run on this computer**.
Die App startet einen lokalen SoulFire-Server. Du brauchst weder Docker noch eine separate Java-Installation.

## 1. App installieren [#1-install-the-app]

<Cards>
<Card title="Windows" href="/docs/start-here/windows">Installiere die Windows-Desktop-App.</Card>
<Card title="macOS" href="/docs/start-here/macos">Installiere die macOS-Desktop-App.</Card>
<Card title="Linux" href="/docs/start-here/linux">Installiere die Linux-Desktop-App mit Flatpak.</Card>
</Cards>

## 2. Einen Bot verbinden [#2-connect-one-bot]

Folge [Deinen ersten Bot verbinden](/docs/start-here/gui-mode).
Du brauchst einen Java-Minecraft-Testserver. Die Anleitung verwendet einen Server im Offline-Modus unter `127.0.0.1:25565`.
Verwende für einen Server im Online-Modus stattdessen ein Microsoft-Konto.

## 3. Nächste Aufgabe wählen [#3-choose-your-next-task]

- [Teste deinen Server](/docs/testing) mit einem wiederholbaren Ablauf.
- [Erstelle ein visuelles Skript](/docs/scripting), ohne Code zu schreiben.
- [Nutze das SDK](/docs/sdk) mit TypeScript oder Python.
