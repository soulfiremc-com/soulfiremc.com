Beginne mit der Desktop-App und **Integrated server (local)**.
Die App startet ein lokales SoulFire-Backend. Du brauchst weder Docker noch eine separate Java-Installation.

## 1. App installieren [#1-install-the-app]

<Cards>
<Card title="Windows" href="/docs/start-here/windows">Installiere die Windows-Desktop-App.</Card>
<Card title="macOS" href="/docs/start-here/macos">Installiere die macOS-Desktop-App.</Card>
<Card title="Linux" href="/docs/start-here/linux">Installiere die Linux-Desktop-App mit Flatpak.</Card>
</Cards>

## 2. Einen Bot verbinden [#2-connect-one-bot]

Folge [Deinen ersten Bot verbinden](/docs/start-here/gui-mode).
Halte einen Minecraft-Testserver bereit. Die Anleitung verwendet einen Java-Server im Offline-Modus unter `127.0.0.1:25565`.
Verwende für einen Server im Online-Modus stattdessen ein Microsoft-Konto.

Der Test ist erfolgreich, wenn der Bot beitritt, eine sichtbare Nachricht sendet und nach dem Stoppen die Verbindung trennt.
