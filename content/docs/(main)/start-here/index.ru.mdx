Начните с приложения и режима **Встроенный сервер (локально)**. В английском приложении он называется **Run on this computer**.
Приложение запускает локальный сервер SoulFire, поэтому Docker и отдельная установка Java не нужны.

## 2. Подключите одного бота [#2-connect-one-bot]

Следуйте уроку [Подключите первого бота](/docs/start-here/gui-mode).
Нужен тестовый Java-сервер Minecraft. В уроке используется сервер в офлайн-режиме по адресу `127.0.0.1:25565`.
Для сервера в онлайн-режиме используйте аккаунт Microsoft.
