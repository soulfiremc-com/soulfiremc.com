Начните с приложения и режима **Integrated server (local)**.
Приложение запускает локальную серверную часть SoulFire, поэтому Docker и отдельная установка Java не нужны.

## 2. Подключите одного бота [#2-connect-one-bot]

Следуйте уроку [Подключите первого бота](/docs/start-here/gui-mode).
Подготовьте тестовый сервер Minecraft. В уроке используется Java-сервер в офлайн-режиме по адресу `127.0.0.1:25565`.
Для сервера в онлайн-режиме используйте аккаунт Microsoft.

Успех означает, что бот подключился, отправил видимое сообщение и отключился после остановки.
