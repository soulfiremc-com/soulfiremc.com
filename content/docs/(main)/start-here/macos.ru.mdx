## Установка SoulFire [#install-soulfire]

<Steps>
  <Step>
    ### Скачайте SoulFire [#download-soulfire]
    Откройте [страницу загрузки](/download).
    Страница определяет вашу систему и процессор. Убедитесь, что выбрана macOS, затем скачайте файл `.dmg`.
  </Step>

  <Step>
    ### Скопируйте SoulFire в «Программы» [#copy-soulfire-to-applications]
    Откройте скачанный файл `.dmg`.
    Перетащите **SoulFire** в папку **Программы** (**Applications**), затем извлеките образ диска.
  </Step>

  <Step>
    ### Разрешите первый запуск [#allow-the-first-start]
    Откройте SoulFire из папки «Программы».
    macOS блокирует первый запуск, потому что приложение не нотаризовано Apple.

    В macOS 15 и новее:

    1. Закройте предупреждение.
    2. Откройте **Системные настройки**, затем **Конфиденциальность и безопасность**.
    3. Прокрутите до раздела **Безопасность** и выберите **Все равно открыть** (**Open Anyway**) рядом с сообщением о SoulFire.
    4. Подтвердите паролем, затем снова выберите **Все равно открыть**.

    В macOS 14 и старее удерживайте `Control`, щёлкните приложение и дважды выберите **Открыть**.
    Это нужно сделать один раз для каждой установленной версии.
  </Step>

  <Step>
    ### Запустите SoulFire [#start-soulfire]
    SoulFire откроется на экране **Подключение к серверу SoulFire** (по-английски **Choose where SoulFire runs**).
    В дальнейшем открывайте SoulFire из папки «Программы» или через Launchpad.
  </Step>
</Steps>
