Use this section to set up SoulFire for the first time.
If you get stuck, ask in our [Discord server](https://soulfiremc.com/discord).

<Callout type="info">
  Most users can start with `Integrated server (local)` in the GUI.
  It is the simplest path and does not require a separate backend.
</Callout>

## Legal disclaimer

<Callout type="warning" emoji="⚠️">
  Use SoulFire only on servers that you own or have permission to test.
  Make sure that your hosting provider permits automated bot testing.
  You are responsible for unauthorized use of SoulFire.
</Callout>

## Recommended path

Read these pages in order:

1. [Choose Your Setup](/docs/start-here/choose-your-setup)
2. Install SoulFire on your platform
3. [Run Your First Session in GUI Mode](/docs/start-here/gui-mode)
