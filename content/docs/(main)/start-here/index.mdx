Start with the desktop app and **Integrated server (local)**.
The app starts a local SoulFire backend, so you do not need Docker or a separate Java installation.

## 1. Install the app

<Cards>
  <Card title="Windows" href="/docs/start-here/windows">Install the Windows desktop app.</Card>
  <Card title="macOS" href="/docs/start-here/macos">Install the macOS desktop app.</Card>
  <Card title="Linux" href="/docs/start-here/linux">Install the Linux desktop app with Flatpak.</Card>
</Cards>

## 2. Connect one bot

Follow [Connect your first bot](/docs/start-here/gui-mode).
Keep a Minecraft test server ready. The tutorial uses an offline-mode Java server at `127.0.0.1:25565`.
For an online-mode server, use a Microsoft account instead.

Success means that the bot joins, sends a visible message, and disconnects after you stop it.

## 3. Choose your next task

- [Test your server](/docs/testing) with a repeatable run.
- [Build a visual script](/docs/scripting) without writing code.
- [Use the SDK](/docs/sdk) from TypeScript or Python.

## Other installation paths

Read [Choose your setup](/docs/start-here/choose-your-setup) if you need a remote backend or terminal workflow.
A backend that stays online belongs in [Run a SoulFire server](/docs/server).
Use [CLI mode](/docs/start-here/cli-mode) for a terminal-driven session.
