SoulFire has two parts. A **client** is the app that you use to control bots: the desktop app (GUI) or the terminal client (CLI).
A **SoulFire server** runs the bots and connects them to the Minecraft server.
The client can start its own server on your computer, or connect to a server that runs somewhere else.

| If you want to... | Start with... | Why |
| --- | --- | --- |
| Learn SoulFire with the least setup | [Connect your first bot](/docs/start-here/gui-mode) | The desktop app starts a server on your computer for you |
| Keep bots running on a VPS, or share them with other users | [Dedicated server](/docs/server) | Bots keep running when you close the client, and several clients can connect |
| Automate from a terminal, or use a computer without a desktop | [CLI mode](/docs/start-here/cli-mode) | Works in scripts and SSH sessions |

## Recommended paths

### New user

1. [Install SoulFire](/docs/start-here).
2. [Connect your first bot](/docs/start-here/gui-mode).
3. Use the [User guide](/docs/how-to) for accounts, proxies, plugins, and integrations.

### Remote operator

1. [Deploy a dedicated server](/docs/server) with the setup script, Docker, or Java.
2. In the desktop app, select **Connect to a SoulFire server**. Enter the server URL and an access token. [Server access](/docs/server/access) shows how to create the token.
3. Use [Server administration](/docs/server) for upgrades, backups, and access.

### Automation user

1. Decide whether the CLI starts its own server or connects to a remote one.
2. Read [CLI mode](/docs/start-here/cli-mode).
3. Read [Automation](/docs/automation) and choose an automation method.
4. Keep [CLI flags](/docs/reference/cli-flags) open as your reference.
