## Install SoulFire

<Steps>
  <Step>
    ### Download SoulFire
    Open the [download page](/download).
    The page detects your system and processor. Check that it shows Windows, then download the `.exe` installer.
  </Step>

  <Step>
    ### Run the installer
    Open the download folder and double-click the installer.

    Microsoft Defender SmartScreen can show **Windows protected your PC**, because the installer is new and not code-signed.
    Select **More info**, then select **Run anyway**.
  </Step>

  <Step>
    ### Start SoulFire
    The installer needs no input. It installs SoulFire for your user account and opens the app on the **Choose where SoulFire runs** screen.
    Later, open SoulFire from the Start menu or the desktop shortcut.
  </Step>
</Steps>
