## Install SoulFire

Follow these steps to install SoulFire on Windows.

<Steps>
  <Step>
    ### Download SoulFire
    Open the [download page](/download).
    Select Windows and your CPU architecture, then download the latest `.exe` installer.
  </Step>

  <Step>
    ### Run the installer
    Open the download folder and double-click the installer.
  </Step>

  <Step>
    ### Accept the warning
    Your browser or Windows Defender can show a warning.
    In Windows Defender, select **More info**, then select **Run anyway**.

    This is common with newer software that has not built up much download history yet.
  </Step>

  <Step>
    ### Follow the installer
    Follow the instructions.
    Keep the default settings unless you need to change them.
  </Step>

  <Step>
    ### Start SoulFire
    Open SoulFire from the Start menu, desktop icon, or Windows search.
  </Step>
</Steps>
