## Zainstaluj SoulFire [#install-soulfire]

<Steps>
  <Step>
    ### Pobierz SoulFire [#download-soulfire]
    Otwórz [stronę pobierania](/download).
    Strona wykrywa system i procesor. Sprawdź, czy wybrany jest Windows, a następnie pobierz instalator `.exe`.
  </Step>

  <Step>
    ### Uruchom instalator [#run-the-installer]
    Otwórz folder pobranych plików i kliknij dwukrotnie instalator.

    Microsoft Defender SmartScreen może wyświetlić komunikat **System Windows ochronił ten komputer**, ponieważ instalator jest nowy i nie ma podpisu cyfrowego.
    Wybierz **Więcej informacji**, a następnie **Uruchom mimo to**.
  </Step>

  <Step>
    ### Uruchom SoulFire [#start-soulfire]
    Instalator nie wymaga żadnych działań. Instaluje SoulFire dla Twojego konta użytkownika i otwiera aplikację na ekranie **Połącz z serwerem SoulFire** (po angielsku **Choose where SoulFire runs**).
    Później otwieraj SoulFire z menu Start lub skrótu na pulpicie.
  </Step>
</Steps>
