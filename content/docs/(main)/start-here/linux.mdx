## Install SoulFire

<Steps>
  <Step>
    ### Install Flatpak
    Install `flatpak` with the [official installation guide](https://flathub.org/setup).
  </Step>

  <Step>
    ### Install SoulFire
    Run this command in a terminal:
    ```bash
    flatpak install flathub com.soulfiremc.soulfire
    ```

    Accept the prompts. For screenshots and release details, see [SoulFire on Flathub](https://flathub.org/apps/com.soulfiremc.soulfire).
  </Step>

  <Step>
    ### Start SoulFire
    Open SoulFire from the application menu.
    You can also run `flatpak run com.soulfiremc.soulfire{:bash}` in a terminal.
  </Step>
</Steps>

If you do not want Flatpak, the [GitHub release](https://github.com/soulfiremc-com/SoulFireClient/releases/latest) also has AppImage, `.deb`, `.rpm`, and pacman packages.
