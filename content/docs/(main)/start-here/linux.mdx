## Install SoulFire

Follow these steps to install SoulFire on Linux.

<Steps>
  <Step>
    ### Install Flatpak
    Install `flatpak` with the [official installation guide](https://flatpak.org/setup/).
  </Step>

  <Step>
    ### Install SoulFire
    Run this command in a terminal:
    ```bash
    flatpak install flathub com.soulfiremc.soulfire
    ```

    See the [`flatpak` package on Flathub
    page](https://flathub.org/apps/com.soulfiremc.soulfire).
  </Step>

  <Step>
    ### Complete the installation
    Accept the installation prompts.
  </Step>

  <Step>
    ### Start SoulFire
    Open SoulFire from the application menu.
    You can also run `flatpak run com.soulfiremc.soulfire{:bash}` in a terminal.
  </Step>
</Steps>
