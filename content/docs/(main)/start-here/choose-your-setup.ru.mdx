## Из чего состоит SoulFire [#what-each-part-means]

### Клиент GUI [#gui-client]

GUI это приложение для компьютера.
В нём вы создаёте инстансы, меняете настройки, следите за состоянием ботов и управляете плагинами и скриптами.

### Клиент CLI [#cli-client]

CLI это клиент для терминала.
Используйте его для автоматизации, сеансов SSH или систем без рабочего стола.

### Встроенный сервер [#integrated-server]

GUI и CLI включают сервер SoulFire.
Вы можете запускать ботов на своём компьютере без отдельного сервера.

### Выделенный сервер [#dedicated-server]

Выделенный сервер запускает SoulFire отдельно, обычно на другом компьютере.
Клиенты GUI и CLI подключаются к нему по сети.

## Рекомендуемые пути [#recommended-paths]

### Новый пользователь [#new-user]

1. [Установите SoulFire](/docs/start-here)
2. [Запустите первых ботов в режиме GUI](/docs/start-here/gui-mode)
3. Используйте [Руководство пользователя](/docs/how-to) для настройки аккаунтов, прокси, плагинов и интеграций

### Работа с удалённым сервером [#remote-operator]

1. [Разверните выделенный сервер](/docs/server/automated-setup)
2. Подключитесь из GUI по URL сервера и токену доступа
3. Используйте [Руководство пользователя](/docs/how-to) для текущего администрирования

### Автоматизация [#automation-user]

1. Решите, будет ли CLI использовать локальный или удалённый сервер
2. Прочитайте [Режим CLI](/docs/start-here/cli-mode)
3. Прочитайте [Автоматизация](/docs/automation) и выберите способ автоматизации
4. Держите [флаги CLI](/docs/reference/cli-flags) под рукой как справочник
