## Test without proxies first

Remove the proxies from the project and connect one bot.
With an empty proxy list, bots connect directly.

- If the bot still fails, the proxies are not the cause. See [Cannot connect or times out](/docs/troubleshooting/cannot-connect-or-times-out).
- If the bot connects, add one known-good proxy, then a small sample, then the full list. The step where the failure returns shows the cause.

## Common problems

| Symptom | Cause | Fix |
| --- | --- | --- |
| The import rejects lines | The format does not match the selected type | Compare the lines with [Proxy formats](/docs/reference/proxy-formats). Use HTTP, SOCKS4, or SOCKS5. SoulFire does not accept `https://` proxy URLs. |
| A file with several proxy types fails | Only URI lines can mix types | Write each line as a URI, such as `socks5://user:pass@host:port` |
| Proxies authenticate with the wrong user | The username and password fields are in the wrong order | Use `host:port:user:pass` or `user:pass@host:port` |
| Proxies pass the check but bots time out | The check used another server | Set **Proxy check address** to your target server and run the check again |
| Repeated proxy connect timeouts | The proxy is dead, overloaded, rate-limited, or blocked by the target | Remove the failing proxies. Test a small sample before you add more. |
| Some bots stay queued and never start | Every proxy has reached **Bots per proxy** | Add proxies, or raise **Bots per proxy**. `-1` means no limit. |
| Account import fails only with proxies | **Use proxies for account auth** sends Microsoft logins through the proxies | Turn that setting off, import the accounts, then turn it on again. See [Accounts and authentication](/docs/troubleshooting/accounts-and-authentication). |

## Check proxies against your target

The proxy check connects to **Proxy check address**, which defaults to `mc.hypixel.net`.
A proxy can pass that check and still fail to reach your server, for example when your server blocks its network.

1. Set **Proxy check address** to the server that you test.
2. Run the proxy check.
3. Remove the proxies that fail, then connect bots.

<Callout type="info">
  A large proxy list can contain many unstable proxies.
  Proxy quality matters more than list size.
</Callout>

## What to capture before you report it

- proxy type and whether the proxies need a username and password
- whether the same test works without proxies
- whether **Use proxies for account auth** is on
- the exact timeout or proxy error text
